# 📸 Image Naming Guide — Downtown Luka Digital Menu

To assign images to any menu item, simply drop the image file into the `Downtown Luka Menu/uploads/` directory.

The website has a built-in resolver that automatically detects these files. You can save your images as **`.jpg`**, **`.png`**, or **`.jpeg`** formats.
